# Mini Programa 1ª VA: Lista de Exercícios Práticos

Lista de exercícios práticos da disciplina de **Processamento de Imagens**, resolvida com OpenCV no notebook `1ª_Lista_de_Exercícios_Práticos.ipynb`.

## Exercícios

1. **Redução de ruído** com operações básicas entre imagens.
2. **Destacar os aviões** de uma imagem usando operações entre imagens.
3. **Rotação** para deixar uma torre reta.
4. **Interpolação** para melhorar a resolução: vizinho mais próximo e bicúbica.
5. **Melhoria de qualidade** com brilho, contraste e equalização de histograma.
6. **Efeito sépia** alterando os canais de cor.
7. **Binarização:** equalização com CLAHE, ajuste de contraste e limiarização para obter uma versão binarizada da imagem.

## Como executar

```bash
pip install opencv-python numpy matplotlib jupyter
jupyter notebook
```

> As imagens usadas nos exercícios não estão versionadas nesta pasta. Ajuste os caminhos no notebook para as imagens no seu computador.

## Tecnologias

Python · OpenCV · NumPy · Matplotlib
