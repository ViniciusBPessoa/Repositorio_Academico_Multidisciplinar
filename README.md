# Repositório Acadêmico Multidisciplinar

Bem-vindo ao Repositório Acadêmico Multidisciplinar! Este é um espaço dedicado à exposição dos trabalhos e projetos que desenvolvi nas disciplinas do curso de **Bacharelado em Ciência da Computação (BCC) da UFRPE**. O repositório é apenas para leitura: modificações são feitas somente pelo autor, para preservar a integridade dos trabalhos aqui disponibilizados.

## Objetivo

Reunir, num só lugar, uma biblioteca de trabalhos e projetos em áreas como Inteligência Artificial, Redes Neurais, Arquitetura de Computadores, Sistemas Operacionais, Computação Gráfica e Ciência de Dados. Os projetos principais têm o próprio README, com os detalhes de cada um.
